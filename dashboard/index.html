Method

How it works on NVIDIA ALCHEMI

A team of agents with no boss. Each owns a different job or checking method. They coordinate only through a shared results board, and a result is trusted only when independent evidence agrees.

Evidence

Results by trust level

Every simulated value next to the measured one, with the referees' reasons. Known materials are checked against measurements; anything nobody has measured is labelled PREDICTION.

Collective capability

Single agent vs pipeline vs our collective

The same tasks, budget and tools for each set-up, including NVIDIA's own traps: an ill-posed property, thermostat-damped diffusion and superheated crystals. Does a team of referees catch what one agent ships?

Reported, not hidden

What failed

Failed runs, flagged results and methods that did not hold up. Failures are evidence, so they stay on the page.
